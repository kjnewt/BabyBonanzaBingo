# 🍼 Baby Bonanza Bingo

An interactive virtual Baby Shower Bingo game created for **Baby Bonanza
2026**.

The game is designed for virtual celebrations and allows each guest to
generate and play their own randomized Bingo card directly in their
browser.

## 🎉 Features

-   Interactive 5×5 Bingo card
-   Randomized card generation
-   84 possible Baby Bonanza prompts
-   Center FREE SPACE
-   Click or tap squares to mark them
-   Clear marks and restart
-   Generate a new randomized card
-   Automatic Bingo detection
-   Bingo celebration message
-   Responsive design for desktop, tablet, and mobile
-   Print / Save as PDF option
-   Browser remembers the player's card after refresh
-   No login or account required

## 🎲 How to Play

1.  Open the Baby Bonanza Bingo website.
2.  Your Bingo card will automatically be generated.
3.  Keep the card open during the virtual baby shower.
4.  When something on your card happens, click or tap that square.
5.  Get five marked spaces in a row:
    -   Across
    -   Down
    -   Diagonally
6.  When you get five in a row, the game will announce **BINGO!**
7.  Shout BINGO, unmute, wave wildly, or announce your win in the
    meeting chat. 🎉

## 👶 Randomized Cards

Each card contains:

-   24 randomly selected Baby Bonanza prompts
-   1 center FREE SPACE

Prompts are selected from a pool of 84 possibilities and shuffled into
different positions.

This allows a group of players to use the **same website link** while
receiving different Bingo cards.

## 💻 Technology

Baby Bonanza Bingo is a lightweight static web application built with:

-   HTML
-   CSS
-   Vanilla JavaScript
-   Browser Local Storage

There are no external libraries, databases, accounts, or installations
required.

## 🌐 GitHub Pages

This project can be hosted directly using GitHub Pages.

The main game file should be named:

`index.html`

Once GitHub Pages is enabled for the repository, players can access the
game through the published GitHub Pages URL.

## 📱 Recommended Setup for Virtual Events

For the easiest experience:

**Computer:** Keep the virtual shower open on the computer and Baby
Bonanza Bingo in another browser window.

**Phone:** Open the Bingo website on a phone while participating in the
virtual shower from a computer.

## 🔒 Player Data

The game does not collect or transmit player information.

The player's randomized card and marked spaces are stored locally in
their browser using Local Storage.

Refreshing the page will therefore preserve the player's current card.
